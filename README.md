# ratidzorungwandi5-svg.github.io

This repository hosts a personal website built for GitHub Pages.

## Files

- `index.html` — main homepage content
- `styles.css` — page styles and layout
- `script.js` — small interactive behavior (dark mode toggle, mobile menu)

## Customize

Replace placeholders such as `Your Name`, `hello@example.com`, and project descriptions with your personal details.

## Publish

1. Commit and push to the `main` branch.
2. Enable GitHub Pages in repository settings.
3. Choose the `main` branch and `/` folder as the source.

Your site should be available at `https://ratidzorungwandi5-svg.github.io/` once published.
